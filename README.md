## Featured Data Engineering Projects

### Azure Weather Data Platform

*Batch Data Engineering Project on Microsoft Azure*

<img src="./assets/azure-weather-data-platform.png" width="100%" alt="Architecture of the Azure Weather Data Platform batch data pipeline">

An end-to-end Azure batch data engineering platform that ingests weather data from the OpenWeather API, processes it through a Medallion-style architecture, and exposes curated datasets for analytics. It covers scheduled ingestion, validation, cleansing, standardization, enrichment, PySpark transformations, Delta Lake, analytical serving, monitoring, and secure access with Entra ID/RBAC, Managed Identity, and Key Vault.

`OpenWeather API` → `Azure Data Factory` → `ADLS Gen2` → `Azure Databricks` → `Silver Delta Lake` → `Gold Delta Lake` → `Azure SQL / Synapse` → `Power BI`

**Stack:** Azure Data Factory · ADLS Gen2 · Azure Databricks · PySpark · Delta Lake · Azure SQL · Synapse Analytics · Power BI · Azure Monitor · Azure Key Vault · GitHub/VS Code/CI/CD

[View Repository](https://github.com/yahia-khroufi/azure-weather-data-platform)

### IoTFlow

*Real-Time Data Engineering Platform*

<img src="./assets/iotflow-real-time-data-engineering-platform.png" width="100%" alt="Architecture of the IoTFlow real-time data engineering platform">

IoTFlow is a containerized platform for ingesting, streaming, processing, storing, orchestrating, and visualizing IoT and system metrics—including CPU, RAM, disk, and temperature data. It combines NiFi routing, Kafka streaming, Spark validation and transformations across Raw/Silver/Gold layers, Cassandra storage, Airflow orchestration, and a Streamlit dashboard, with shared Python modules for models, configuration, tests, and utilities.

`IoT / Edge Agent` → `Apache NiFi` → `Apache Kafka` → `Spark Structured Streaming` → `Apache Cassandra` → `Streamlit`  
*Apache Airflow orchestrates workflows and scheduled jobs.*

**Stack:** Python · Docker · Docker Compose · Apache NiFi · Apache Kafka · Apache Spark · Apache Airflow · Apache Cassandra · Streamlit

[View Repository](https://github.com/yahia-khroufi/IoTFlow-Real-Time-Data-Engineering-Platform) · [Watch Demo](https://youtu.be/2abhzypWHvg)
